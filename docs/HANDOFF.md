## 这一版做了什么

把 `/tmp/remotion-map-test` 里验证过的路线动画，做成了一个本地网页工作台。启动命令 `pnpm start`，地址 `http://127.0.0.1:5317`。

### 1. 视频组件（`src/video/`）

| 文件 | 作用 |
| --- | --- |
| `config.ts` | `VideoConfig` 类型。工作台编辑的就是这个对象，预览和渲染都只读它 |
| `timeline.ts` | 纯函数：输入配置和帧号，输出这一帧的相机、轨迹、车头、流光、地标、HUD 数值。地图和 HUD 读同一份结果，所以不会出现轨迹落后于画面 |
| `mapStyle.ts` | 自建底图样式：OpenFreeMap 矢量瓦片按主题配色，楼块 3D 拉伸，路线由暗虚线底线和三层发光轨迹组成 |
| `Hud.tsx` | 顶栏、标题、站点进度条、地标卡、总结卡、仪表盘、署名。坐标取自画幅布局，文字和显隐取自配置 |
| `layout.ts` | 三种画幅的 HUD 坐标和镜头取景。9:16 避开小红书顶栏 0–160px、底栏 1700–1920px、右侧 940px 以外 |
| `themes.ts` | 6 套主题的色值，从之前的对比页原样搬过来 |

和 `/tmp` 版相比的改动：

- 场景参数改成从配置读取，不再写死成都、重庆两条路线。
- **镜头动感滑块**（0–100）同时控制三项：转弯时偏航跟随比例、偏航平滑强度、穿行时的缩放。默认 50 对应之前验证过的成片参数，有单元测试守着。
- **环线自动判断**：起终点很近时，用起点到终点的方向定镜头朝向没有意义，这时改成正北朝上。
- **地图站名方位自动计算**：之前重庆示例是手工写的。现在按收尾全景的朝向找每个站最近的邻居，把文字放到背离邻居的一侧。
- **标题按宽度自动缩小字号**，长标题不会超出安全区。
- 渲染时地图 2 倍超采样，预览时 1 倍，保证预览流畅。

### 2. 本地服务（`server/`）

| 接口 | 作用 |
| --- | --- |
| `GET /api/config` | 是否已填 Key（返回打码后的 Key）、输出目录 |
| `POST /api/key` | 校验并保存 Key：先检查是不是 32 位，再真实调一次高德接口，常见错误码都翻译成具体改法 |
| `GET /api/search` | 高德输入提示，返回坐标已从 GCJ-02 转成 WGS-84 |
| `POST /api/route` | OSRM 骑行路网算路 |
| `POST /api/render` · `GET /api/render/:id` | 渲染任务和进度。一次只跑一个任务，单并发、ANGLE 后端，和成片验证时参数一致 |
| `POST /api/reveal` | 在 Finder 里定位成片，只允许输出目录内的文件 |

- 服务只监听 `127.0.0.1`。
- Key 存在 `config.local.json`，已加入 `.gitignore`，仓库里没有任何 Key。

### 3. 工作台前端（`src/app/`）

- **Key 引导**（`KeyGate.tsx`）：没有 Key 时弹出。三步说明，带直达高德控制台的链接，重点提醒选「Web服务」。
- **四个区**（`Panels.tsx`）：
  - 路线：城市、起终点、途经点；可拖动排序，也可用 ↑↓ 按钮；每个点有“弹地标”开关；最多 5 个途经点；可一键互换起终点。
  - 风格：6 张主题缩略图。
  - 字段：画幅、时长、镜头动感（带“恢复默认”）、8 个组件开关。
  - 文案：所有文字都可编辑。
- **搜索框**（`PlaceSearch.tsx`）：边打字边出候选，防抖 220ms，支持方向键和回车。搜到的地名会自动去掉括号里的分店信息，英文名默认用拼音。
- **默认文案**：根据路线自动生成。用户改过的字段不会被覆盖，“按当前路线重置”可以恢复。
- **路线体检**（`src/shared/health.ts`）：路线太短或太长、车速过快（会给出建议时长）、来回折返超过 300 米、相邻地标不到 150 米。
- **实时预览**（`Preview.tsx`）：`@remotion/player` 播放同一个视频组件，9:16 可叠加小红书遮挡区。
- **状态记忆**：存在浏览器 localStorage，刷新页面不丢。第一次打开载入成都示例。

## 已知限制和后续建议

1. 算路固定用骑行路网，因为驾车路网受单行道影响，常常绕远并出现掉头。用户不能选出行方式，这是按需求有意去掉的。
2. 路线体检只提示，不会自动修复。出现折返时要用户自己换途经点。后续可以做“自动尝试附近主路节点”。
3. 时长和镜头动感只影响时间轴，不会重建地图；主题、画幅、路线变化会重建地图，预览会黑一下再出画面。
4. 首次渲染要先打包工程，约 20 秒；第一次运行还会下载约 81MB 的 Chrome Headless Shell。
5. 公益服务（OSRM、OpenFreeMap）有合理使用限制。如果要大规模分发，建议自建 OSRM 或换商用瓦片。
